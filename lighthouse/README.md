# Аудит доступности

## Страницы

- `index.html`
- `catalog.html`
- `order.html`

Дополнительно проверены `about.html`, `contacts.html` и `account.html`.

## Автоматическая проверка разметки (все 6 страниц, светлая и тёмная тема)

| Проверка | Результат |
| --- | --- |
| `lang="ru"` и уникальный `title` | есть на всех страницах |
| Ссылка пропуска `.skip-link` → `main#main` | есть на всех страницах |
| Ровно один `h1`, без пропуска уровней заголовков | да |
| Изображения без `alt` | 0 |
| Поля формы без связанного `label` | 0 |
| Кнопки и ссылки без доступного имени | 0 |
| Повторяющиеся `id` | 0 |
| `aria-labelledby` / `aria-describedby` / `aria-controls` на несуществующий `id` | 0 |
| Горизонтальный скролл на 360, 430, 768, 1024, 1440 px | нет |

## Ручная проверка

- Tab: skip-link появляется первым, затем меню, карточки, фильтры, поля формы, FAQ, подвал; фокус виден везде.
- Модальное окно: открывается кнопкой «Заказать», фокус переходит внутрь, закрывается Escape, кнопкой «×», «Отмена» и кликом по фону; после закрытия фокус возвращается на кнопку.
- Форма: при ошибке под полем появляется текст, поле получает `aria-invalid="true"`, фокус переходит на первое поле с ошибкой, сводка объявляется скринридером.
- Контраст: основной текст около 16:1, второстепенный текст `#4f5260` около 7:1, белый текст на акцентном `#3d2fd6` около 8:1.

## Как сохранить отчёт Lighthouse

1. Запустить сервер в корне проекта: `python3 -m http.server 8000`.
2. Открыть `http://localhost:8000/index.html` в Google Chrome → DevTools → вкладка **Lighthouse**.
3. Оставить категорию **Accessibility**, режим **Navigation**, нажать **Analyze page load**.
4. В меню отчёта (⋮) выбрать **Save as HTML** и сохранить сюда как `index.html`; повторить для `catalog.html` и `order.html`.
