## Найденные проблемы и исправления

1. **`color-contrast`** — большой декоративный логотип «Вольт» в подвале был текстом с контрастом 1,69:1. Он скрыт от экранных дикторов (`aria-hidden="true"`), но проверка контраста его учитывала. Текст перенесён в CSS: `::before { content: attr(data-text) }`.
2. **`label-content-name-mismatch`** — значок «1» на кнопке чата был внутри кнопки с `aria-label="Чат с консультантом"`, и видимый текст не входил в имя кнопки. Значок вынесен за пределы кнопки.

После исправлений проверка повторена: на всех страницах 0 ошибок.

## Ручная проверка (Lighthouse её не заменяет)

- Tab: первой появляется ссылка пропуска к содержимому, затем меню, карточки, фильтры, поля формы, FAQ, подвал; фокус виден везде.
- Модальное окно: открывается кнопкой «Заказать», закрывается Escape, кнопкой «×», «Отмена» и кликом по фону; фокус возвращается на кнопку.
- Форма: при ошибке под полем появляется текст, поле получает `aria-invalid="true"`, фокус переходит на первое поле с ошибкой, сводка объявляется скринридером.
- Таблица на телефоне в карточном виде сохраняет роли таблицы для экранных дикторов.
- Горизонтального скролла нет на 360, 430, 768, 1024 и 1440 px.

## Как повторить проверку

1. Запустить сервер в корне проекта: `python3 -m http.server 8000`.
2. Открыть `http://localhost:8000/index.html` в Google Chrome → DevTools → вкладка **Lighthouse**.
3. Выбрать категорию **Accessibility**, режим **Navigation** и нажать **Analyze page load**.
