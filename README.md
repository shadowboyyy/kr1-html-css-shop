# Учебный интернет-магазин — контрольная работа №1

## Описание

Тема: «HTML и CSS: разработка многостраничного сайта».

Учебный frontend-проект по дисциплине «Фронтенд и бэкенд разработка». Сайт содержит главную страницу, каталог, описания товаров с характеристиками, форму заявки и контакты. CSS-фреймворки и backend не используются.

## Ссылки

- GitHub Pages: https://shadowboyyy.github.io/kr1-html-css-shop/
- Репозиторий для сдачи в СДО: https://github.com/shadowboyyy/kr1-html-css-shop

## Просмотр проекта

Откройте ссылку GitHub Pages или скачайте репозиторий и откройте `index.html` в браузере. Установка зависимостей и сборка не требуются. Переходы между страницами доступны через общее меню.

После публикации финальных изменений нужно повторно проверить сайт на GitHub Pages: новые страницы появятся там после обновления ветки публикации.

## Используемые технологии

- HTML: семантическая разметка, таблицы, формы и `dialog`.
- CSS: переменные, состояния, Flexbox, Grid, позиционирование и БЭМ.
- JavaScript: открытие и закрытие модального окна, базовая обработка формы.
- Git и GitHub; публикация через GitHub Pages.

## Реализованные элементы

- Пять страниц с уникальными `title`, описаниями и общим меню.
- Семантические элементы `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Якоря `advantages`, `popular`, `contacts` на главной и ссылки на товары в `product.html`.
- Flexbox-навигация, Grid-сетка карточек, Grid-раскладка каталога и страницы товара.
- Карточки с изображением, описанием, ценой и ссылкой на характеристики.
- Таблицы с `caption`, `thead`, `tbody`, `th` и `td`.
- Формы с именем, e-mail, телефоном, товаром, датой связи, темой, комментарием и согласием.
- Модальное окно заявки на главной странице.
- CSS-переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`, подсветка ошибок через `aria-invalid`.
- `relative` у карточки, `absolute` у бейджа «Хит», `sticky` у шапки, `fixed` у кнопки «Наверх» и `z-index`.

Фильтры каталога — статическая разметка: кнопка «Применить» отключена, список товаров не фильтруется. Формы проверяют данные в браузере и показывают учебное подтверждение; данные на сервер не отправляются и не сохраняются. Корзина и полноценная JavaScript-интерактивность не входят в эту работу.

## БЭМ-структура

Основные блоки: `site-header`, `site-nav`, `breadcrumbs`, `hero`, `products-grid`, `product-card`, `catalog-layout`, `catalog-filters`, `filters-form`, `product-details`, `product-table`, `order-page`, `order-dialog`, `order-form`, `button`, `back-to-top`, `site-footer`.

Элементы обозначены через `__`, например `product-card__title`. Модификаторы обозначены через `--`, например `product-card--featured` и `site-nav__link--active`.

## Проверка перед сдачей

1. Открыть все пять страниц, проверить меню, изображения и общий CSS.
2. Проверить якоря на главной, ссылки «Подробнее» в каталоге и кнопку «Наверх».
3. На странице товара проверить таблицы и переход к заявке.
4. На главной нажать «Заказать»: должно открыться модальное окно; кнопка «Закрыть» и Escape закрывают его.
5. В обеих формах отправить пустые поля, неправильный e-mail и телефон — браузер должен показать ошибку.
6. Заполнить имя (не менее двух символов), e-mail, телефон в формате `+7 (900) 000-00-00`, тему и согласие; в отдельной форме также выбрать товар. После отправки появляется сообщение, поля очищаются, модальное окно закрывается.
7. Проверить видимый фокус клавишей Tab и состояния кнопок при наведении.
8. В DevTools проверить `display: flex` у меню, `display: grid` у сеток и свойства позиционирования.
9. После публикации повторить проверку на GitHub Pages. В СДО передать ссылку на репозиторий.

## Постановка контрольной работы №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».
