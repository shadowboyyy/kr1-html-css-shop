# «Вольт» — адаптивный интернет-магазин на HTML и CSS

Многостраничный сайт магазина игр, техники и стильных вещей. Сайт написан на чистом HTML, CSS и JavaScript без CSS-фреймворков, адаптирован под телефоны, планшеты и desktop и проверен на доступность.

## Ссылки

- GitHub Pages: https://shadowboyyy.github.io/kr1-html-css-shop/
- Репозиторий: https://github.com/shadowboyyy/kr1-html-css-shop

## Как открыть

Откройте `index.html` в браузере или ссылку GitHub Pages. Установка зависимостей и сборка не нужны. Для проверки на телефоне удобнее запустить локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Страницы

| Страница | Что на ней |
| --- | --- |
| `index.html` | Hero с витриной, бегущая строка категорий, преимущества, популярные товары, статистика, отзывы, FAQ, призыв оставить заявку |
| `catalog.html` | Каталог из 9 товаров с рабочими фильтрами: категория, цена, «только со скидкой», сортировка, счётчик и пустое состояние |
| `product.html` | Подробные описания, цены, список особенностей и таблица характеристик каждого товара; лента быстрого перехода |
| `order.html` | Форма заявки в две колонки, превью выбранного товара, шаги оформления и контакты |
| `contacts.html` | Карточки способов связи, схема проезда к шоуруму и форма обратной связи |
| `account.html` | Личный кабинет: вход, история заявок, избранное, бонусы и профиль |

На всех страницах общая закреплённая шапка с мобильным меню, переключателем светлой и тёмной темы и входом в кабинет, индикатор прокрутки, большой подвал (навигация, контакты, подписка, соцсети), чат с консультантом и кнопка «Наверх».

## Тема, кабинет и чат

- **Светлая и тёмная тема.** По умолчанию тема берётся из настроек системы, кнопка в шапке переключает её вручную, выбор запоминается. Новая тема раскрывается кругом от кнопки (View Transitions API).
- **Личный кабинет.** Вход по имени и e-mail. В кабинете — заявки, оформленные на сайте, избранные товары (сердечко в карточке каталога), бонусы 5% от суммы заявок и редактирование профиля. Данные профиля подставляются в формы заявки. Всё хранится в `localStorage` браузера.
- **Чат с консультантом.** Кнопка в правом нижнем углу на всех страницах: быстрые вопросы, ответы по доставке, оплате, гарантии, скидкам и подбору товара, ссылки на нужные страницы. Переписка сохраняется в пределах вкладки.

## Технологии

- **HTML**: семантика (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`), `dialog`, `picture`, `srcset`/`sizes`, таблицы с `caption` и `scope`.
- **CSS**: переменные, Flexbox, Grid, `clamp()`, `aspect-ratio`, `position: sticky`, БЭМ, View Transitions между страницами.
- **JavaScript**: мобильное меню, модальное окно, проверка форм с текстовыми ошибками, фильтрация и сортировка каталога, маска телефона, подстановка товара в заявку по ссылке `order.html?product=N`.
- **Motion** (моушн-дизайн): появление первого экрана, поочерёдное появление карточек при прокрутке, счётчики в статистике, индикатор прокрутки, параллакс витрины и логотипа в подвале, пружинные анимации наведения и нажатия, анимация модального окна и меню. При настройке «Уменьшить движение» анимации отключаются, а если библиотека не загрузилась, контент остаётся видимым.

## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта интернет-магазина. Основа взята из контрольной работы №1 (HTML/CSS-версия, без Bootstrap).

## Практическая работа №12

Тема: «Адаптивная вёрстка HTML/CSS-проекта: медиазапросы, изображения, формы и таблицы».

Выполнено:

- добавлен файл `css/responsive.css` и подключён на всех страницах после `style.css`;
- проверен `meta viewport` на всех страницах;
- применён подход Mobile First: базовые стили — для телефона, расширения через `min-width`;
- добавлены медиазапросы для 480, 640, 768, 900, 1024, 1280 и 1440 px;
- адаптирована навигация: на телефоне меню открывается кнопкой, с 768 px — строка ссылок;
- адаптирован hero-блок: одна колонка на телефоне, две колонки с 900 px, заголовок через `clamp()`;
- адаптирована сетка карточек: 1 → 2 → 3 колонки, `minmax(0, 1fr)` и `overflow-wrap: anywhere`;
- адаптирован каталог: на телефоне фильтр стоит перед товарами и сворачивается, с 1024 px — sticky-колонка слева;
- адаптированы изображения: `max-width: 100%`, `aspect-ratio`, `object-fit`, `width`/`height`, `loading="lazy"`;
- добавлены responsive images: `picture` с WebP и JPEG, `srcset` и `sizes` для фото товаров (320, 447/480, 577, 739 px);
- адаптирована форма заявки: одна колонка на телефоне, две колонки с 768 px, широкие поля на всю строку, поля высотой не меньше 44 px;
- адаптирована таблица характеристик: обёртка `.table-wrapper` с горизонтальной прокруткой;
- адаптировано модальное окно: `width: min(100% - 32px, 640px)`, прокрутка содержимого, закреплённый заголовок;
- кнопка «Наверх» не перекрывает контент и появляется только после прокрутки;
- выполнена проверка через DevTools.

## Практическая работа №13

Тема: «A11y-аудит и обеспечение доступности. Использование Lighthouse и анализ проблем доступности».

Выполнено:

- проверена семантическая структура страниц: один `h1`, заголовки идут по порядку `h1 → h2 → h3`;
- добавлена ссылка пропуска к основному содержимому (`.skip-link` → `main#main`);
- проверена навигация с клавиатуры: меню, карточки, фильтры, формы, модальное окно, FAQ;
- добавлен видимый фокус `:focus-visible` (3 px) для всех интерактивных элементов, в тёмном подвале — салатовый;
- проверены изображения: у смысловых — описательный `alt`, у декоративных — пустой `alt=""`;
- проверены формы: у каждого поля есть `label for`, обязательные поля отмечены и пояснены текстом;
- добавлены текстовые сообщения об ошибках, связанные с полем через `aria-describedby`, и `aria-invalid` только у полей с ошибкой; сводка ошибок объявляется через `role="alert"`;
- проверены кнопки и ссылки: действия — `button`, переходы — `a`; у кнопок-иконок есть `aria-label`;
- исправлена контрастность: основной текст `#15161b`, второстепенный `#4f5260` (контраст выше 6:1), акцентный `#3d2fd6` (8:1 на белом);
- проверено модальное окно: `dialog` с `aria-labelledby`, кнопка закрытия «×» с `aria-label`, закрытие по Escape, по фону и кнопке «Отмена»;
- проверена таблица: `caption`, `th scope="col"` и `th scope="row"`, прокручиваемая обёртка доступна с клавиатуры;
- ARIA используется только там, где её нет в HTML: `aria-current`, `aria-expanded`/`aria-controls` у меню и фильтров, `aria-live` у счётчика каталога;
- учтена настройка `prefers-reduced-motion`.

## Исправления доступности

| Было | Стало |
| --- | --- |
| Не было ссылки пропуска к содержимому | Добавлена `.skip-link`, появляется при первом нажатии Tab |
| Ошибки формы показывались только всплывающими подсказками браузера | Текстовые сообщения под каждым полем, `aria-describedby`, `aria-invalid`, сводка с `role="alert"`, фокус на первое поле с ошибкой |

| Хлебные крошки — текст через `::before` | Список `ol` и `aria-current="page"` у текущей страницы |
